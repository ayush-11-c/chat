# 💬 MERN Chat App

A real-time chat application built with the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) featuring:

- ✅ Authentication & Authorization  
- 🧑‍🤝‍🧑 One-on-One and Group Chats  
- 📡 Real-Time Messaging with Socket.IO  
- 📦 Redux for State Management  
- 📊 React Query for Data Fetching and Caching  
- 🎨 Material UI for a clean, responsive UI  
- 🛠️ Admin Dashboard with user, chat, and message controls

## 🚀 Features

### 👤 User Panel
- Register and login (with avatar upload)
- Search users and send/accept friend requests
- Real-time chat with friends and groups
- Create, rename, and manage group chats
- Send text messages and file attachments
- Notification system for friend requests

### 🛡️ Admin Panel
- Secure login for admin
- View all users, chats, and messages
- Dashboard with system statistics

## ⚙️ Tech Stack

- **Frontend:** React.js, Redux Toolkit, React Router, React Query, Material UI  
- **Backend:** Node.js, Express.js, MongoDB, Mongoose  
- **Real-time:** Socket.IO  
- **Validation:** Express Validator  
- **File Uploads:** Multer  
- **Authentication:** JWT + Cookies
